# Explicit Attentionless Language Model — Preliminary Design

*Candidate name: **EXARCH** — EXplicit Attentionless Reasoning with Classification Heuristics*
*(See §Acronym Candidates for alternatives)*

---

## Motivation

Starting from Elhage et al.'s *A Mathematical Framework for Transformer Circuits*:

- **Zero-layer transformers** model bigrams (unembedding applied directly to embedding)
- **One-layer attention-only transformers** are an ensemble of bigram and "skip-trigram" behavior
- **Two-layer transformers** can implement induction heads and more complex algorithms

This raises the question: can we build an explicit, lookup-based system that captures these same computational primitives without attention or backpropagation at all? The motivation is not to compete with transformers on perplexity, but to understand what the core statistical structure of language actually is, made fully legible and inspectable.

Note: this is an entirely different model architecture than WaveletLM. Placing it here for archival/follow-up purposes.

---

## Architecture Overview

The system is a layered cascade of explicit lookup tables, falling back from most-complex to least-complex, with a learned classifier (the "amygdala") as the final arbiter when all tables are too sparse.

---

## Layer 1: Skip-N-Gram Table

### Definition

A **skip-3-gram** has the form `A ... BCD`, where:

- `A` is a *distant anchor token* seen somewhere earlier in the context window
- `BC` is an *immediately contiguous bigram* preceding the prediction position
- `D` is the token being predicted

The table `T[a][b][c]` stores a distribution over next tokens `D`, conditioned on anchor `a` having appeared recently and bigram `(b, c)` being the immediate context.

This is semantically different from a standard trigram despite the same V³ shape. A standard trigram conditions on a contiguous window `(A, B, C) → D`; the skip-3-gram captures **contextual modulation** — the same local bigram `BC` can yield very different D-distributions depending on the distant anchor `A`. For example: *"...the president... walked into the room"* vs. *"...the criminal... walked into the room"* — the `(walked, into)` bigram is identical, but the anchor shifts probability mass over the next token substantially.

### Higher-Order Skip-N-Grams

Generalize to `A ... BC...` with one anchor token and a contiguous (N−1)-gram as immediate context. `N = 3` is the practical ceiling with a vocabulary of ~10,000 tokens:

- Dense table: V³ = 10¹² cells — intractable
- After frequency thresholding to V' ≈ 1,000 active tokens: V'³ = 10⁹ — feasible, sparse

### Subsumption Property

A skip-N-gram table marginalizes to all lower-order tables. Only the highest-order table is needed; smaller tables are recoverable by marginalization. This means no redundant storage is required for the full cascade.

### Anchor Recency Policy

The simplest implementation treats anchor presence as binary (A appeared anywhere in the last N tokens). A soft alternative weights the anchor's contribution by recency, making it behave more like a decaying attention than a boolean flag. Binary is cheaper and likely sufficient for a first pass.

---

## Layer 2: Standard Trigram / Bigram

Standard contiguous n-gram tables, stored as sparse count matrices with shared marginals (~20% storage overhead over raw counts). Shared marginals enable probability normalization and Kneser-Ney-style discounting without storing separate tables for each order.

---

## Layer 3: Top-k Induction Buffer

A static, pre-computed table of the `k ≈ 5` most frequent successor tokens for each vocabulary token, built from the training corpus. This is **not** a dynamic context buffer — purely frequency-based, computed once before deployment. Provides a floor prediction for any token, including in zero-context situations.

---

## Layer 4: Amygdala Classifier

A fast, pre-trained classifier (e.g., Linear SVM on TF-IDF features) that captures:

- **Sentiment polarity**: Emotional charge of the context
- **Familiarity**: How closely the current context matches frequently-seen patterns
- **Anchoring**: Presence of named entities, specific cases, known examples

### Training

The amygdala is trained once on a labeled version of the full corpus (labels generated by an LLM or human annotators), then frozen. Its pre-computation can be performed before inference begins, allowing its contextual signal to modulate all other layers from the start.

### Role in the Cascade

The amygdala serves two functions:

1. **Sub-tensor selector** (see §Sub-Tensor Specialization): its context vector acts as a soft weight over specialized sub-tensors throughout the cascade
2. **Final-fallback predictor**: when all lookup tables are too sparse, retrieve the k most similar prior contexts by TF-IDF cosine similarity and use their empirical next-token distributions as an oracle

---

## Sub-Tensor Specialization

Rather than one monolithic skip-3-gram tensor, the table is factored into specialized sub-tensors for different token classes:

| Sub-tensor | Token class | Approx. vocabulary size |
|---|---|---|
| Syntactic | Function words (articles, prepositions, conjunctions) | ~200 |
| Affective | Sentiment-bearing words | ~500 |
| Domain | Topic-specific terminology | Variable |
| Anchoring | Named entities, proper nouns | Variable |

Each sub-tensor is a literal slice of the full tensor (a subset along the vocabulary dimension). The amygdala's context vector acts as a soft weight over these sub-tensors at each cascade step — high emotional charge upweights the affective sub-tensor; recognized domain context upweights the domain sub-tensor, and so on.

---

## Inference: The Layer Cascade

Prediction proceeds top-down, backing off when a layer lacks confidence:

1. **Skip-3-gram lookup** → compute entropy of predicted distribution; if below threshold (confident), emit prediction
2. **Trigram / skip-2-gram** → same entropy check
3. **Bigram** → same entropy check
4. **Unigram** → same entropy check
5. **Amygdala**: contextual similarity retrieval → use matched prior context distributions as oracle
6. **Tie-break**: if two or more prior contexts for the same relation are contextually indistinguishable, sample uniformly between them

### Entropy Trigger

The backoff condition at each layer is whether the predictive distribution's entropy exceeds a threshold. A flat distribution signals that the layer lacks sufficient data, and the question is passed down. This mirrors the proposed role of the anterior cingulate cortex (ACC) as a conflict/uncertainty monitor — an idea explored further in §Brain Structure Mapping.

### Tie-Breaking

When the same `(A, BC)` relation has been observed in two distinct prior contexts with conflicting outcomes, the amygdala context vector selects which prior context the current one more closely resembles. If contextual disambiguation is still not possible, the model samples uniformly between the tied candidates rather than guessing deterministically.

## Learning and Count Management

### Intrinsic Scoring: Discriminative Utility

A naive "relevance tally" — incrementing when an n-gram's top prediction was correct — reduces to raw count. A more useful measure is **discriminative utility**: how much does this n-gram *reduce* prediction entropy versus the simpler layer below it?

Formally, for skip-3-gram entry `(a, b, c)`:

```
utility = log p(D | A=a, BC=bc) − log p(D | BC=bc)
```

This is pointwise mutual information (PMI) between the anchor and the prediction. High-PMI entries are those where the distant anchor provides genuinely useful information beyond the local bigram. This can be tracked as a secondary tally without modifying the main count table, and can inform pruning decisions (drop entries whose utility is consistently near zero).

### Count Decay as Implicit Optimization

A count with multiplicative decay at each timestep is an **exponentially weighted moving average (EWMA)** of the binary indicator sequence. This produces backprop-reminiscent behavior:

- Patterns that stop being useful decay out of the distribution
- Patterns that keep recurring strengthen and become high-confidence
- The distribution continuously reshapes toward recent data

The key difference from backpropagation: credit does not propagate *backward* through layers. Each layer's counts update independently from the observed ground-truth token, not from upstream error signals. This is more like a multi-armed bandit reward signal than a true gradient — but for a lookup table, this is likely sufficient, and it is entirely interpretable.

### Continual Learning: Three Timescales

| Timescale | Mechanism |
|---|---|
| Immediate | Count increment for every observed `(a, bc, d)` triple |
| Medium | Amygdala gradient update on novel contexts + replay buffer of recent examples |
| Slow | Periodic count decay (exponential or scheduled halving) |

This three-timescale structure mirrors the complementary learning systems hypothesis in cognitive neuroscience: fast binding of specific episodes, slower integration into stable statistical knowledge, and gradual forgetting of stale patterns.

## Brain Structure Mapping

| Brain region | System component |
|---|---|
| Hippocampus | Episodic retrieval (contextual similarity lookup) |
| Basal ganglia | Count-weighted sampling over candidate tokens |
| Prefrontal cortex | Rolling topic window / working context |
| Broca's area | POS-tag n-gram sub-tensor (syntactic structure) |
| Anterior cingulate cortex (ACC) | Entropy check / confidence monitor (backoff trigger) |
| Default mode network (DMN) | Entity tracker (anchor token registry) |
| Thalamus | Threshold logic (backoff conditions) |
| Amygdala | Sentiment / familiarity / anchoring classifier |

## Wavelet Analogy

The skip-N-gram structure has a natural analogy to wavelet decomposition: the distant anchor `A` plays the role of a coarse (low-frequency) component, while the immediate contiguous context `BC` plays the role of a fine (high-frequency) component. Together, they condition prediction on two scales simultaneously — exactly the multi-resolution decomposition that wavelets perform on signals.

A more explicit fusion of this architecture with wavelet-based channel decomposition (as in WaveletLM) is not yet explored here; this design works purely with raw tokens and no channel structure.
